# LunaUpdateSrv
A very simple update server for Project Luna.
## Setup Instructions

1. **Install flask from pip**<br>
   Run the following command to install flask from pip:  
   ```bash
   pip install flask
   ```

2. **Prepare the update files**
   - `update.zip` – the update package
   - `update.json` – metadata for the update

3. **Start the server**<br>
   The console will display a local URL, open it in your browser to view the JSON or visit `/file` to get the update package.
